## ✨ Features

- 🎨 **Neon gradient snake** — green → cyan → purple body
- 👀 **Animated eyes** that follow direction
- 👅 **Flickering tongue** animation
- 💫 **Particle explosions** on eat & death
- 🔆 **Pulsating glowing food**
- 🏆 **Persistent high score** saved to local file
- 🖱️ **Click restart button** or press Space
- 🌑 **Dark UI** with subtle grid background

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/amiraliSite/snake-game.git
cd snake-game

# Install
pip install -r requirements.txt

# Run
python main.py
